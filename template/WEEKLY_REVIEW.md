# WEEKLY_REVIEW.md — 每週六復盤清單

每週六被 `weekly_review.ps1` 喚醒時，依序做「用數據修正選題」的復盤。**只做分析與更新記憶，不發片、不上傳。**

## 步驟

### 1. 更新數據
- 跑 `python pipeline\fetch_analytics.py` 刷新 `ANALYTICS.md`（拉最新觀看/留存）。失敗（缺 token_analytics.json）就用現有的，不要卡住。

### 2. 盤點「這週」表現
比對 `MEMORY.md` 已發布清單的日期，鎖定**最近 7 天**發布的影片，從 `ANALYTICS.md` 看它們的觀看數與留存%：
- 找出本週**爆款**（觀看或留存明顯高於其他）——記下它的主題、鉤子寫法、比喻、格式（Shorts/長片）。
- 找出本週**冷門**（個位數觀看或留存 <30%）——記下它可能的敗因（主題太抽象？鉤子弱？縮圖不跳？）。
- 跟歷史標竿比（目前：顯卡130、Context Window 90觀看/67%留存）：本週有沒有新標竿？

### 3. 歸納模式（這是重點，要有判斷）
- 哪一類主題持續有效（有痛感 > 有畫面 > 抽象，這個排序還成立嗎？）
- 哪種鉤子/比喻/縮圖強調詞這週最吃香？
- 有沒有該淘汰或該加碼的方向？

### 4. 回寫 `MEMORY.md`（把洞察變成下週的行動）
- 「觀眾回饋觀察」：新增一行 `YYYY-MM-DD 週復盤：<本週爆款/冷門/新標竿一句話>`。
- 「已涵蓋主題 → 待發題庫」：依本週學到的，**重排 A/B/C 級順序**、把驗證有效的方向往前挪、加 1~3 個新的候選主題、拿掉明顯沒搞頭的。
- 「下次改進方向」：寫 1~3 條**具體**可執行的微調（例：某類縮圖強調詞、某種鉤子開法、配樂音量）。
- 若發現嚴重問題（連續低觀看、某格式全面失靈），寫進「待金主爸爸處理」。

### 5. 結束
- 這是分析任務，做完就結束。**不要產片、不要上傳**（那是每日心跳的事）。
- 可順手在 `DIARY.md` 寫一句本週心得。

原則：一次復盤只更新「選題方向與記憶」，讓接下來一週的每日心跳照新方向選題。
