# COMMENTS.md — 觀眾留言回覆準則與紀錄

> 金主 2026-11-18 訂：**主動回應每一位留言者，態度懇切，並虛心學習。**
> 每次心跳發完片後（HEARTBEAT 第 2 步）處理：`python pipeline\comments.py list` 看待回留言，逐則回。

## 怎麼回
1. **先謝謝**，具體點出對方說了什麼（不要罐頭「感謝留言」）。用阿遠的口吻：親切、謙虛、像消防員學長，不浮誇。
2. **對方提建議或補充** → 真心肯定好的地方，說阿遠學到什麼。可以當下一支題材的，記進 MEMORY.md 待發題庫並寫「觀眾 @xxx 建議」。
3. **對方指出錯誤或質疑** → 先查證（防災題照 PROGRAMS.md 紅線查官方來源，AI 知識查原始資料）：
   - **對方對、我們錯**：坦白承認並更正，附來源；在影片下另發一則「📌 更正」留言、影片描述最前面補更正，
     並在 MEMORY.md「待金主爸爸處理」寫一行「請手動置頂 <影片> 的更正留言」（API 無法置頂）。教訓寫進對應規則檔。
   - **查不清楚**：誠實說「阿遠再去查證」，不要硬拗、不要隨便認錯。
   - **我們對**：溫和說明並附來源，不爭辯、不說教。
4. **提問** → 簡短回答；防災／急救照官方說法並附來源，查不到就說不確定、建議洽 119 或官方單位。
5. 長度 1～4 句、300 字以內。回覆文字先寫成 UTF-8 檔，再 `python pipeline\comments.py reply <threadId> <檔案>`。

## 不要做
- 不捏造事實、數字、AI 回答；不承諾做不到的事（「下週一定做」）。
- 不給醫療診斷、用藥品項或劑量（照官方「常用藥、個人處方藥」說法，請對方問醫師藥師）。
- 不透露金主個資，不回私人聯絡方式。
- **廣告、詐騙連結、謾罵、政治挑釁 → 不回**（在紀錄寫一行「略過：原因」即可）。對酸言酸語可以禮貌回一句，不對罵。
- 不刪觀眾留言、不檢舉，交給金主決定。
